# 基金小助理

窗口右缘的悬浮面板：查大盘与基金行情、维护自选与持仓、按分组管理基金、跟踪每日净值与盈亏。

安装方法（DSH 插件页 / 本地目录 / `plugin_manager`）见 [README.md](../README.md#在-dsh-中安装)。

## 用法

- 点击竖排的「基金」悬浮条展开或收起面板。标题栏总资产常驻，内容区可滚动且无滚动条。
- **今日行情**：
  - **大盘指数**：分页展示，每张卡片含名称、代码、现价、涨跌幅与涨跌额；点 ☆ 加入自选，已自选显示实心 ★。
  - **全部基金**：可搜索（代码/名称/拼音）、按类型筛选、按涨幅排序，一键加自选。默认仅显示在售基金，可在设置切换「全部基金」。
  - **ETF 基金**：内置主题 ETF 实时价格。
- **我的自选**：
  - **自选大盘指数**：与大盘指数同款卡片，点 ✕ 取消自选。
  - **自选基金**：已是持仓的基金显示「＋加仓 / －减仓」且不能取消自选；未持仓的显示「＋加入持仓」和「✕取消自选」。
- **持仓基金**：
  - 顶部分组栏切换「全部 / 自定义分组 / 未分组」（未分组排最后）。
  - 资产总览、排序（今日涨跌/持有收益/持有金额）、紧凑卡片列表。
  - 卡片默认显示名称、持仓金额、今日盈亏、净值、成本、份额、收益率；点右侧箭头展开可执行加仓、减仓、编辑、移入分组、移除。
  - 点卡片上的「▦ 分组名」可把该基金移入任意分组或移回未分组。
  - **未分组**页可勾选多只基金，选择目标组后一键批量分配。

## 添加与金额制

**添加基金**：搜索 6 位代码、名称或拼音简码（如 `HXCZHH`）。金额输入框在最前——

- 填 **金额** 时按最新净值自动折算：`份额 = 金额 ÷ 净值`、`成本 = 该净值`。份额、成本可留空（一般无需填写）。
- 若当时取不到净值，记为**待确认**并保存金额，等下一次取到净值后自动折算并落库。

**批量导入**：每行 `基金代码 金额`（空格/逗号/Tab 分隔，支持 ¥ 与千分位），例如：

```text
000001 1000
161725 500.50
005827, 2000
```

同一代码多行会累加；按最新净值自动折算份额与成本。

**加仓 / 减仓**：只填金额，份额按确认日净值自动折算（普通基金 T+1，QDII T+2）；确认前金额已计入持仓金额，卡片显示「待确认 ¥金额」。

## 显示内容

- 每只基金的最新净值、昨日净值、今日涨跌与昨日涨跌；今日净值未公布时标「按昨日净值」，持有金额与收益改用昨日净值计算。
- 持仓金额 = 份额 × 最新净值 + 待确认买入金额；今日盈亏、持有收益与收益率见顶部汇总与卡片指标行。
- 面板顶部汇总总资产、总今日盈亏与总收益率。
- 行情按「设置」中的间隔自动刷新（默认 60 秒），也可手动刷新。

**拖动 Tab**：一级 Tab（今日行情 / 我的自选 / 持仓基金 / 设置）与二级 Tab 都可拖动调整顺序；顺序与当前页签保存在本机，键盘可用 `Alt + ← / →` 移动焦点页签。

## 数据与隐私

- 持仓保存在本机 `~/.dsh/fund-tracker/fund-tracker.db`（SQLite），按 DSH 登录账号隔离，不会上传。
- 个人页面需登录 DSH 账号；行情页为公开信息，无需登录。
- 每日净值、基金基础库与在售标记来自东方财富公开接口；Host 后台定时自动同步，即使不打开面板也会更新。
- 新账号首次打开会播种 6 只演示持仓 + 4 只自选（成本贴近真实净值、盈亏混合），可直接使用或删除后录入自己的数据。

## 已知边界

- 部分场内 ETF 无盘中估值，涨跌显示「—」。
- 数据仅供参考，不构成投资建议。
