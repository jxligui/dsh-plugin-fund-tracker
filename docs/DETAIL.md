# 基金小助理

窗口右缘的悬浮面板：查大盘与主题基金、维护自选与持仓，跟踪每日盈亏与持有收益。

安装方法（DSH 插件页 / 本地目录 / `plugin_manager`）见 [README.md](../README.md#在-dsh-中安装)。

## 用法

- 点击竖排的「基金」悬浮条展开或收起面板。
- **今日行情**：指数网格（可在「设置 → 编辑指数」中勾选）、主题基金与 ETF 实时行情、基金检索。
- **我的自选**：关注的指数和基金。点「加入持仓」并填写份额成本后，这只基金**仍保留在自选**，同时出现在「我的基金」。
- **我的基金**：持仓列表，显示持有金额、今日盈亏、持有收益与收益率。每张卡片右上有醒目的「操作」按钮，展开后可加仓 / 减仓、编辑份额成本、加入我的自选（保留持仓）或移除。
- **设置**：刷新间隔、指数显示选择、基金基础库状态与手动更新。

**添加**：输入 6 位代码、名称或拼音简码（如 `HXCZHH`）。份额、成本价、金额可只填需要的：
- 填 **持仓金额**（添加 / 编辑）或 **加仓金额 / 减仓金额**（卡片操作）时，按当时最新净值自动折算份额：`份额 = 金额 ÷ 净值`（保留 2 位小数），成本价留空时取同一净值。
- 若当时取不到净值，不猜份额：记为 **待确认** 并保存金额，等下一次取到净值后自动折算并落库（通常是第二天）。

**拖动 Tab**：一级 Tab（今日行情 / 我的自选 / 我的基金 / 设置）与二级 Tab（指数 / 基金 / ETF）都可拖动调整顺序；顺序和当前停留的页签保存在本机，下次打开仍生效。键盘可用 `Alt + ← / →` 移动焦点页签。

**导入**：粘贴支付宝（基金持有）、微信（基金）或华夏基金的持仓文本并确认。每行中的 6 位代码会被识别，出现「份额 / 成本 / 金额」数字时一并采纳；没有份额的行作为自选。

## 显示内容

- 每只基金的最新净值估算、**昨日净值**、今日涨跌与昨日涨跌。
- 已知份额与成本时，额外显示持有金额、今日盈亏、持有收益与收益率。
- **今日净值尚未公布时**（净值日期不是今天），卡片会标「按昨日净值」，持有金额与持有收益改用昨日净值计算，今日盈亏暂记为 0。
- 面板顶部汇总总资产、总今日盈亏与总收益率。
- 行情按「设置」中的间隔自动刷新（默认 60 秒），也可手动刷新。

## 数据与隐私

- 持仓保存在本机 `~/.dsh/fund-tracker/fund-tracker.db`（SQLite），按 DSH 登录账号隔离，不会上传。
- 个人页面需登录 DSH 账号；行情页为公开信息，无需登录。
- 行情来自东方财富公开接口：盘中的估值约每分钟更新，收盘后回到最新披露净值；休市日显示最近交易日数据。

## 已知边界

- 部分场内 ETF 无盘中估值，涨跌显示「—」。
- 数据仅供参考，不构成投资建议。
