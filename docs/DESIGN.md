# 基金管家（fund-tracker）设计文档

一款 DeepSeek Harness（DSH）插件：在 Web 界面右缘提供常驻悬浮入口，查看大盘行情、主题基金，维护自选与持仓，跟踪每日盈亏与持有收益。参照养基宝类基金工具的核心功能设计。

## 1. 总体架构

```
fund-tracker/                        目录结构（按层拆分，便于迭代）
├── package.json / cordis.patch.yml   bundle 清单与插件注册
├── index.js                          Host 入口：依赖注入、SQLite 生命周期、账号状态
├── lib/
│   ├── constants.js                  外部数据源 URL、指数库定义、公共常量
│   ├── store.js                      SQLite 持久层（建表、持仓 CRUD、基础库刷新、用户配置）
│   ├── market.js                     外部行情适配器（fundgz / push2 / 搜索 / 历史净值）
│   └── routes.js                     HTTP 路由处理（公开 API + 登录保护的私有 API）
├── client.js                         Client UI（单 bundle 契约，按功能区分节）
├── locale/                           插件元数据（zh/en）
├── docs/                             设计文档、schema.sql、详情页
└── icon.svg
```

## 2. 数据设计

数据库 Schema 见 [schema.sql](schema.sql)，共 6 张表：

| 表 | 用途 | 说明 |
|---|---|---|
| `holdings` | 个人持仓/自选 | 主键 (account, code)，按 DSH 登录账号隔离；`watch=1` 表示在自选，与是否有份额互相独立（可同时在自选和持仓）；`pending_amount` 为待确认金额 |
| `fund_base` | 基金基础库 | 代码/名称/拼音简码/全拼/类型；基金每 24h 自动全量刷新（约 2.8 万条），内置指数以 kind='index' 一并写入 |
| `index_base` | 指数库 | 代码/名称/拼音/secid/分类，供指数列表与检索 |
| `etf_base` | ETF 主题库 | 内置主题 ETF 清单，行情走交易所实时价格 |
| `user_settings` | 用户设置 | 按账号存放 JSON 值（如指数显示选择） |
| `meta` | 元数据 | 基础库最后刷新时间、各账号 demo 播种标记等 |

**基础库数据源**：`fund.eastmoney.com/js/fundcode_search.js` 全量列表（字段：代码、拼音简码、名称、类型、全拼）。插件激活时异步刷新（24 小时节流）；面板底部「基金基础库」行显示条数与上次更新时间，并提供「立即更新」按钮强制手动刷新（需登录）。

**行情数据不落库**：指数与估值始终实时获取（push2 / fundgz），内存缓存即可，避免数据过期。

## 3. 隐私与登录门禁

- 个人数据只存在本机 DSH Profile 目录的 SQLite 文件中，不经过任何外部服务器
- 「我的基金」读写前校验 `deepseekAccount.getState()`：`status === 'credential-stored'` 视为已登录；未登录时 API 返回 403，面板锁定该标签，仅行情页可看
- 行情页为公开信息，不要求登录

## 4. 刷新策略

- 面板内「刷新间隔」下拉：15 / 30 / 60 / 120 / 300 秒，默认 60 秒，选择持久化在浏览器本地
- 打开面板立即刷新一次；后续按所选间隔轮询

## 5. 收益计算口径

- 净值取 `fundgz` 的估值（`gsz`），昨日净值取 `dwjz`；`jzrq` 不是今天说明今日净值尚未公布
- **今日净值未公布时，持有金额与持有收益改用昨日净值计算**，并在卡片上标「按昨日净值」；
  今日盈亏此时记为 0（不再用估值涨跌幅反推）
- `持有金额 = 份额 × 计算净值`
- `今日盈亏 = 持有金额 × 涨跌幅 / (100 + 涨跌幅)`（由涨跌幅反推昨日基数）
- `持有收益 = (计算净值 − 成本价) × 份额`；`收益率 = 计算净值 / 成本价 − 1`
- 汇总行同时给出总资产、总今日盈亏、总收益率

## 6. 功能清单

| 模块 | 功能 |
|---|---|
| 行情页 | 8 大指数实时卡片、12 个主题基金估值列表、一键加入自选 |
| 我的自选 | 关注指数与基金；「加入持仓」记录份额成本后仍保留在自选，可继续查看 |
| 我的基金 | 资产总览、排序（今日涨跌/持有收益/持有金额）、卡片列表、行内编辑份额成本、加仓/减仓、加入我的自选（保留持仓）、移除 |
| 金额录入 | 持仓金额 / 加仓金额自动按当时净值折算份额；取不到净值时记为「待确认」，下次取到净值后自动折算并落库 |
| 添加 | 本地库搜索（代码/名称/拼音简码如 `HXCZHH`）、远程搜索兜底、手动输码 |
| 详情 | 最新净值、成立以来涨幅、六档区间涨幅、近 3 月净值走势图 |
| 导入 | 粘贴支付宝/微信/华夏持仓文本，自动识别代码与份额/成本/金额 |
| Tab 布局 | 一级、二级 Tab 均可拖动排序，顺序与当前页保存在浏览器本地 |
| 安全 | 未登录锁定个人页；数据本地 SQLite 持久化 |

## 7. 自测机制（专家模式）

`test/` 目录包含一套无需启动 DSH 的自测层：

- `test/harness-mock.mjs` — 模拟宿主契约（`webServer.register` 必须带 `kind` 字段等），契约错误在测试期即失败
- `test/routes.test.mjs` — 全 API 集成测试：注册、debug 自诊断、会话、指数/基金分页、拼音检索、持仓增删改查、用户设置、行情适配器（真实网络可选）

运行方式（Node ≥ 22，自带 node:sqlite 与 test runner）：

```
node --test test/routes.test.mjs
```

注意：测试通过 `lib/store.js` 直接打开真实的 `~/.dsh/fund-tracker/fund-tracker.db`（`FT_TEST_PROFILE` / `DSH_PROFILE_DIR` 均不生效），因此首次运行前需先确保基础库已填充（约 2.8 万条基金、29 条指数）；行情相关用例会访问东方财富真实接口，无网络时仍会执行但只断言返回结构。

规则：任何 Host 端改动必须先通过全部测试再安装（install_bundle）。

## 8. 已知边界

- fundgz 估值为盘中估算（约 1 分钟更新），收盘后回退到最新披露净值；ETF 可后续切换 push2 实时价格
- 部分场内 ETF 无盘中估值，涨跌显示「—」
